      Onde ficam seus dados

      Os registros ficam salvos somente neste navegador, neste aparelho (armazenamento local do navegador). Nada é enviado para a internet.

      • Não há sincronização entre celular e computador, nem entre navegadores diferentes no mesmo aparelho.
      • Os dados continuam salvos ao fechar a página, mas podem ser apagados se você limpar os dados de navegação, usar aba anônima ou desinstalar o navegador. No iPhone, o Safari pode apagar dados de sites não usados por 7 dias — adicione à Tela de Início para evitar isso.
      • Para se proteger e para levar os dados a outro aparelho, use Baixar backup e depois Restaurar backup no outro aparelho.

      Backup

      Restaurar substitui todos os registros atuais deste navegador pelos do arquivo. Uma cópia dos dados atuais é guardada antes, e pode ser recuperada com “Desfazer última restauração”.
